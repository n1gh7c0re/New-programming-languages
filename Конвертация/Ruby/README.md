# Task 07 (Ruby) — Конвертация CSV → JSON с нормализацией полей
## Описание
Программа читает CSV-файл, нормализует заголовки (убирает пробелы, преобразует в нижний регистр и snake_case), конвертирует некоторые поля (даты в ISO формат, числовые строки в числа), выводит JSON-массив объектов.

## Входные данные
Файл `input.csv` — строки формата:
```csv
First Name, Last Name, Birth Date, Salary
John, Doe, 1990-05-15, "50000"
```

## Выходные данные
Файл `output.json` — массив объектов с нормализованными полями:
```json
[
  {
    "first_name": "John",
    "last_name": "Doe", 
    "birth_date": "1990-05-15",
    "salary": 50000
  }
]
```

## Как запускать
* Убедитесь, что `input.csv` находится в корне проекта
* Запустите:
  ```
  ruby script.rb
  ```
* Итоговый файл: `output.json`
