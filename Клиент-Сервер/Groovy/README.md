# Task 12 (Groovy) — Асинхронный HTTP-клиент
## Описание
Скрипт читает файл `requests.json`, содержащий массив объектов с URL и полезной нагрузкой (payload). 
Скрипт выполняет асинхронные параллельные POST-запросы к указанным адресам.
Результаты (статус, тело ответа, время выполнения) собираются и записываются в файл `responses.json`.
## Входные данные
Файл `requests.json` — массив объектов: 
```json
{"url": "...", "payload": {...} }
```
## Выходные данные
Файл `responses.json` — массив объектов с результатами:
```json
{"url": "...", "status": 201, "body": "...", "time_ms": ..., "error": null}
```
## Как запускать
* Убедитесь, что Groovy установлен и `requests.json` находится в корне проекта.
* Запустите сервер  в терминале:
  ```
  groovy AsyncClient.groovy
  ```
* Результаты в файле `responses.json`
