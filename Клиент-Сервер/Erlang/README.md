# Task 11 (Erlang) — TCP-сервер-эхо + выполнение команд из файла

## Описание
При запуске программа читает `commands.txt` (список разрешённых команд: `TIME`, `REVERSE`, `UPPER`) и конфигурацию из `server_config.json`, после чего поднимает TCP-сервер, который принимает подключения, выводит эхо-ответ и, если строка начинается с разрешённой команды, выполняет её и добавляет результат в `server.log`.

## Входные данные
- **commands.txt** — список команд (по одной строке):
  ```txt
  TIME
  REVERSE
  UPPER
  ```  
- **server_config.json** — JSON с полем порта: `{ "port": 5555 }`.

## Выходные данные
- **server.log** — лог всех выполненных команд и их результатов.

## Как запускать
* Убедитесь, что Erlang установлен и файлы `commands.txt` + `server_config.json` в корне проекта.
* Запустите сервер:
  ```
  escript tcp_server.erl
  ```
* Подключитесь в отдельном терминале (с помощью Python-клиента `tcp_client.py`):
  ```
  python tcp_client.py
  ```
* Тестируйте строки:
  ```
  > UPPER abababa
  UPPER abababa
  RESULT: ABABABA
  ```
* Для выхода введите пустую строку.
* Результаты в файле `server.log`
