

# Task 01 (Rust) — Параллельная обработка URL

## Описание

Программа читает список URL из файла `input_urls.txt`, распределяет их по пулу потоков (количество потоков задаётся в `config.json`) и имитирует «загрузку» с помощью случайного `sleep`.
Для каждого URL формируется JSON-объект со следующими полями:

* `url` — адрес
* `thread_id` — номер потока, обработавшего URL
* `time_ms` — длительность «загрузки» в миллисекундах
* `status` — `"success"`

Все результаты сохраняются в файл `log.json`.

## Входные данные

* Файл `input_urls.txt` — каждый URL на новой строке
* Файл `config.json` — параметры:

```json
{ "threads": 4, "min_ms": 100, "max_ms": 1000 }
```

## Выходные данные

Файл `log.json` — массив JSON-объектов:

```json
[
  {"url":"http://example.com","thread_id":1,"time_ms":253,"status":"success"},
  ...
]
```

## Как запускать

* Убедитесь, что файлы `input_urls.txt` и `config.json` находятся рядом с программой
* Скомпилируйте проект:

```
cargo build
```

* Запустите:

```
cargo run
```

* Проверьте результат в `log.json`
