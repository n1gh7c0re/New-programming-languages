# Task 02 (D) — Многопоточный подсчёт слов в файле

## Описание

Программа читает большой текст из файла `input.txt` и разбивает его на несколько блоков (количество потоков задаётся в `config.json`).
Каждый поток подсчитывает частоту встречаемости слов в своём блоке. Затем все локальные частоты объединяются и сортируются по убыванию.

## Входные данные

* Файл `input.txt` — произвольный текст
* Файл `config.json`:

```json
{ "threads": 4 }
```

## Выходные данные

Файл `word_counts.csv` с колонками:

```
word,count
```

## Как запускать

* Проверьте наличие файлов `input.txt` и `config.json`
* Скомпилируйте:

```
dmd word_count.d
```

* Запустите:

```
./word_count.exe
```

* Посмотрите результаты в `word_counts.csv`
