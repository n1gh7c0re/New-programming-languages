
# Task 03 (Scala) — Параллельная генерация мини-отчётов

## Описание

Программа читает CSV-файл `data.csv` с записями вида:

```
id,value
```

Данные разбиваются на чанки фиксированного размера (`chunk_size`) и обрабатываются в параллельных задачах.
Для каждого чанка вычисляются:

* сумма (`sum`)
* среднее (`avg`)
* максимум (`max`)

Каждый поток сохраняет промежуточный JSON, затем эти файлы объединяются в один итоговый `reports.json`.

## Входные данные

* Файл `data.csv` — строки формата `id,value`
* Файл `config.json`:

```json
{ "threads": 4, "min_ms": 100, "max_ms": 800 }
```

## Выходные данные

Файл `reports.json` вида:

```json
[
  {"chunk":0,"sum":..., "avg":..., "max":...},
  {"chunk":1,"sum":..., "avg":..., "max":...},
  ...
]
```

## Как запускать

* Убедитесь, что `data.csv` и `config.json` находятся в корне проекта
* Соберите проект:

```
sbt compile
```

* Запустите:

```
sbt run
```

* Итоговый файл: `reports.json`
