# Task 14 (Swift) — Парсер текстовых форм (регулярки) → JSON

## Описание

Программа читает файл заявок `forms.txt`, каждая заявка — это блок в свободном текстовом виде.  
Из каждого блока с помощью регулярных выражений извлекаются поля:

* `Name: ...`
* `Phone: ...`
* `Email: ...`

После обработки всех блоков формируется JSON-массив объектов вида:

```json
{
  "name": "...",
  "phone": "...",
  "email": "..."
}

```
## Входные данные

Файл `forms.txt`, например:
```
Name: Ivan Ivanov
Phone: +7 999 123-45-67
Email: ivan@example.com
```
## Выходные данные

Файл `forms.json`:
```json
{
  "name": "Ivan Ivanov",
  "phone": "+7 999 123-45-67",
  "email": "ivan@example.com"
}
```

## Как запускать

* Установить Swift (Swift 5.7+).

* Убедиться, что файл `forms.txt` лежит рядом с программой.

* Скомпилировать:
  ```
  swiftc forms_parser.swift -o forms_parser
  ```
* Запустить:
  ```
  ./forms_parser
  ```
* Результаты в файле `forms.json`
