# Task 13 (Lisp — Common Lisp) — Парсинг логов регулярками: извлечение IP и времён

## Описание

Программа читает веб-лог `access.log`, построчно извлекает из каждой строки:

* IP-адрес,
* timestamp (`[28/Nov/2025:10:00:15 +0300]`),
* путь запроса (например, `/index.html`),

используя регулярные выражения. Далее подсчитывает:

* количество запросов по каждому IP,
* количество запросов по каждому пути.

Результат сохраняется в CSV-файл `summary.csv` со структурой:

```
type,key,count
ip,192.168.1.1,123
path,/index.html,456
```

## Входные данные

Файл `access.log` — обычный лог веб-сервера Apache/Nginx, формат примерно:

```
192.168.1.1 - - [28/Nov/2025:10:00:15 +0300] "GET /index.html HTTP/1.1" 200 1234
```

## Выходные данные

Файл `summary.csv`:

```
type,key,count
ip,192.168.1.1,123
path,/index.html,456
```

## Как запускать

* Установить Common Lisp (например, SBCL).
* Убедиться, что файл `access.log` находится в рабочей директории.
* Запустите SBCL в терминале:
  ```
  sbcl
  ```
* Загрузите файл:
  ```
  * (load "parse_logs.lisp")
  ```
* Результаты в файле `summary.csv`
