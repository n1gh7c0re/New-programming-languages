# Task 05 (OCaml) — Рекурсивное слияние k отсортированных списков
## Описание
Программа читает k отсортированных списков чисел из файла `lists.json` и сливает их в один отсортированный список с помощью рекурсивного метода «разделяй и властвуй». Вычисляется количество сравнений (сложность) и результат.
## Входные данные
* Файл `lists.json` — массив списков:
```json
[[1,3,5],[2,4],[0,7,8]]
```
## Выходные данные
Файл `merged.json` вида:
```json
{ "result": [0,1,2,3,4,5,7,8], "comparisons": 9 }
```
## Как запускать
* Убедитесь, что `lists.json` находится в корне проекта
* Скомпилируйте:
```
ocamlfind ocamlc -o main.exe -package yojson -linkpkg main.ml
```
* Запустите:
```
.\main.exe
```
* Итоговый файл: `merged.json`
