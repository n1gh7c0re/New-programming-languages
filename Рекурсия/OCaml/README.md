# Task 05 (OCaml) — Рекурсивное слияние k отсортированных списков
## Описание
Программа читает k отсортированных списков чисел из файла `lists.json` и сливает их в один отсортированный список с помощью рекурсивного метода «разделяй и властвуй». Вычисляется количество сравнений (сложность) и результат.
