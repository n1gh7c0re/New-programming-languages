# Task 06 (ML — Standard ML) — Рекурсивные сочетания (combinations)
## Описание
Программа рекурсивно генерирует все k-элементные сочетания из n-элементного списка строк из файла `input.json`. Каждое сочетание записывается в отдельной строке файла.
## Входные данные
* Файл `input.json`:
```json
{ "items": ["a","b","c","d"], "k": 2 }
```
## Выходные данные
Файл `combinations.txt` вида:
```
a b
a c
...
```
## Как запускать
* Убедитесь, что `input.json` находится в корне проекта
* Запустите:
```
sml main.sml
```
* Итоговый файл: `combinations.txt`
